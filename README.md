# Claude skills I use

The skills behind my videos on Instagram ([@liaichi.ai](https://www.instagram.com/liaichi.ai/)) and the app I'm building, [Pilooot](https://pilooot.io).

A **skill** is a folder with one file, `SKILL.md`. The top says what it does and when to use it; the rest is your instructions. Claude reads the description and uses the skill by itself when the job comes up, the same way every time.

## Start your own

Copy [`template/SKILL.md`](template/SKILL.md) into `~/.claude/skills/my-skill/SKILL.md`, change the description and the steps, and open Claude Code.
